# commit-conventions

## O que faz
Instrui o assistente de IA a gerar mensagens de commit no padrão
**Conventional Commits**, em português, com regras de tamanho e imperativo.

## Quando usar
Em qualquer repositório do time onde se queira histórico de commits padronizado
e legível (útil para changelogs e bisect).

## Como instalar
```bash
skills install commit-conventions
```

## Após instalar
Nada além de instalar: a instrução passa a valer automaticamente para a
ferramenta de IA escolhida (Claude via `CLAUDE.md`, Copilot via
`copilot-instructions.md`, etc.).
